    Detailed Description¶

    Wire values (frame types, flow status, field limits) are taken from ISO 15765-2 for classical CAN (8 data bytes) with normal addressing. The result codes are library values: the standard defines the N_Result names, not their numbers.

    ** **

    • Function return codes: ISOTP_OK, ISOTP_ERROR, ISOTP_BUSY.
    • Frame types (N_PCItype) and flow status values.
    • Frame layout limits: ISOTP_CAN_DL, ISOTP_SF_MAX_DL, ...
    • N_Result codes reported by the link: ISOTP_N_OK, ...
    • Big-endian helpers: isotp_get_u32_be, isotp_put_u32_be.
